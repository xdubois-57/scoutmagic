Les groupes sont les espaces de discussion privés de l'unité : un
groupe par section, plus des groupes sur invitation. Vous ne voyez que
les vôtres ; un groupe dont vous ne faites pas partie n'existe tout
simplement pas pour vous. L'onglet « Archives » garde les groupes des
années passées, en lecture seule.

## Publier un message

Écrivez jusqu'à 5000 caractères, joignez jusqu'à quatre photos ou
vidéos, et mentionnez quelqu'un en tapant « @ » suivi de son nom — la
personne citée est prévenue. Un lien tapé dans le texte est détecté
tout seul et son aperçu s'affiche. Dans certains groupes, seuls les
animateurs publient : vous pouvez alors toujours commenter, réagir et
répondre aux sondages.

Vous pouvez modifier votre message pendant **quinze minutes** après sa
publication ; au-delà, il reste tel quel (ou se supprime). Chaque
message se signe automatiquement de votre nom — pensez à le renseigner
dans « Mon compte » si la page vous le demande.

## Commenter et réagir

Chaque message accepte des réponses (2000 caractères, une image) et
six réactions au choix — une seule par personne, recliquer la change
ou la retire. En touchant le compteur, vous voyez qui a réagi.
L'auteur d'un message voit combien de membres l'ont vu.

## Les sondages

Un message peut porter un sondage. Touchez une réponse pour voter ;
selon le sondage, vous répondez pour vous, ou une fois pour chacun de
vos enfants — la page vous demande alors pour qui.

Lesquels d'entre eux, c'est le groupe qui le décide. Dans le groupe
d'une section, seuls ceux qui en font partie : la question posée est
celle de la section. Ailleurs — un camp, un projet, un groupe de
l'unité — vous répondez pour tous, ceux du groupe en premier et les
autres sous « Hors de ce groupe ».

Les résultats montrent les totaux, jamais qui a voté quoi. Tant que le
groupe est ouvert, vous pouvez changer d'avis.

## Signaler un contenu

Le menu « ⋮ » d'un message permet de le signaler aux animateurs qui
modèrent le groupe. Le signalement est confidentiel : l'auteur du
message n'en saura rien, et vous ne recevrez pas de compte rendu.
Plusieurs signalements masquent le message en attendant une décision.
