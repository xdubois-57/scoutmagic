Le calendrier d'un bien montre les réservations et les dates que l'unité
garde pour elle — un week-end d'unité, des travaux, un camp. Les jours
rayés sont réservés par l'unité. Une réservation peut tomber sur les
mêmes jours : les deux restent visibles, et chacune se traite de son
côté.

## Bloquer et libérer des jours

Touchez un jour pour le réserver pour l'unité ; touchez-le de nouveau
pour le remettre en location. Pour plusieurs jours, gardez le doigt
appuyé un instant sur le premier, puis glissez jusqu'au dernier ; à la
souris, cliquez et glissez. Le premier jour décide : s'il était libre,
tout le geste bloque ; s'il était déjà réservé par l'unité, tout le geste
libère. Un message permet d'annuler le geste dans les secondes qui
suivent. Les jours passés ne réagissent pas.

## Les périodes

Une période réservée bloque toujours le bien entier, quel que soit son
nombre d'exemplaires. Le calendrier montre un mois à la fois : une
longue période se bloque en un geste par mois, et les morceaux se
rejoignent tout seuls. Le motif d'une période se donne dans la liste
sous le calendrier, d'où l'on peut aussi la supprimer d'un coup. Le
calendrier public montre ces jours comme « occupé », sans jamais dire
pourquoi.
