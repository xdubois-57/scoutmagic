Quand l'unité attend un paiement de votre part — une cotisation, un
camp, un week-end — un bandeau apparaît sur la page d'accueil avec le
total, et le détail par enfant.

## Sur la page de chaque enfant

Le bloc de paiement donne tout ce qu'il faut : le montant, le
bénéficiaire, l'IBAN, la communication structurée, et un code QR à
scanner avec votre application bancaire.

Le montant affiché est ce qu'il **reste** à payer. Si vous avez déjà
versé une partie, c'est le solde qui est demandé, jamais la somme de
départ.

## Un virement par enfant

C'est la seule chose que nous vous demandons de respecter. Chaque enfant
a **sa** communication structurée, et c'est elle qui fait qu'un virement
se rattache tout seul à la bonne demande en arrivant.

Un virement groupé pour trois enfants arrive sous une seule
communication : quelqu'un doit alors le répartir à la main, et
l'intendant vous recontactera peut-être pour savoir ce qui couvre quoi.

## Si vous venez de payer

Le bandeau indique la date du dernier extrait bancaire chargé par
l'unité. Un virement met généralement un à deux jours ouvrables à
apparaître : entre le moment où vous payez et celui où le site le voit,
il est normal que la demande reste affichée.

Le bandeau disparaît de lui-même quand tout est réglé. Rien ne se coche
à la main, ni de votre côté ni du nôtre.

> Le code QR ne s'affiche pas dans votre logiciel de messagerie ? Il
> bloque les images, c'est un réglage courant. Les informations écrites
> sous le code suffisent pour faire le virement à la main.
