imap Disponible. Sans elle : le courrier entrant n'est plus relevé.
PHP, base de données, écriture PHP 8.3 · MySQL joignable · storage/ accessible en écriture.

Sauvegardes manuelles

La place disponible se lit sur Configuration › Stockage, mesurée volume par volume.

Que faut-il sauvegarder ?
Rien à saisir : l'archive est chiffrée avec un mot de passe que le site génère. Il vous sera affiché au moment du téléchargement.

Elle est préparée en arrière-plan. Vous recevrez une notification quand elle sera prête, et elle apparaîtra dans la liste ci-dessous.

Ce serveur ne sait pas chiffrer les archives. La configuration seule, le site complet et la base de données partiront sans chiffrement — ne les laissez pas traîner. La sauvegarde portable est indisponible : elle contient les clés du site et ne peut pas partir en clair.

À demander à votre hébergeur : activer l'extension openssl de PHP — elle suffit à ce site pour chiffrer lui-même. À défaut, que l'extension zip soit compilée contre libzip 1.2 ou plus avec le support du chiffrement.

Aucune archive ne reprend le contenu d'un emplacement de stockage — ni la galerie photo, ni les autres. Chaque emplacement a son propre cycle de vie : Configuration › Stockage.

Réinitialisation

Ces actions sont irréversibles sans restauration manuelle. Une sauvegarde de sécurité est prise automatiquement avant chaque action.
Déplacée telle quelle depuis la page Maintenance actuelle, moins la restauration, qui rejoint « Sauvegardes récentes ». Les deux blocs ci-dessous arrivent dans leur état actuel.

Paramètres par défaut

Réinitialise tous les paramètres, généraux et modules, à leurs valeurs par défaut. Ne touche ni aux comptes, ni aux membres, ni aux contenus, ni aux fichiers.

Réinitialisation complète

Efface définitivement toutes les données du site. Le prochain accès déclenchera l'assistant d'installation, comme pour un site neuf.

Les dossiers déclarés comme emplacements de stockage ne sont pas effacés : leur contenu n'est repris dans aucune archive, il serait donc perdu sans retour. Le site ne les référencera plus ; supprimez-les vous-même si vous vouliez repartir d'un disque vide.
