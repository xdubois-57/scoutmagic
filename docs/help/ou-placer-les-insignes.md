La place de chaque insigne sur l'uniforme n'est pas décidée par l'unité :
c'est la fédération Les Scouts qui la fixe, et qui publie le guide à
jour. Le site ne le recopie pas, il vous y envoie :
[Uniforme : où coudre les écussons](https://lesscouts.be/fr/news/uniforme-ou-coudre-les-ecussons).

## Cherchez votre branche

Le guide est organisé **par branche** — Baladins, Louveteaux,
Éclaireurs, Pionniers, Routiers — parce que l'uniforme change d'une
branche à l'autre. Repérez celle de votre enfant : sa page en affiche
le nom et le logo.

Pour chaque branche, le guide distingue ce qui se porte **pour toutes
et tous** de ce qui est **optionnel**. Les animateurs et les cadres y
trouvent aussi leur uniforme.

## Où trouver le lien sur le site

- En haut de la page Sections, visible sans être connecté.
- Sur la page de votre enfant, dans la carte de sa branche, sous le
  bouton « En savoir plus » : « Où coudre les insignes sur l'uniforme ? ».

Le lien s'ouvre dans un nouvel onglet, sur le site de la fédération.
